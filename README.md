# Мебель — лендинг под залив рекламы

Next.js (App Router) + Tailwind CSS. Чёрный фон, синий акцент, шрифт
Unbounded для заголовков + Inter для текста, засечки-размерные линии как
у чертежа мебели вместо стандартных неоновых подсветок.

## Запуск локально

```bash
pnpm install
pnpm dev
```

Открыть http://localhost:3000

## Структура

- `app/page.tsx` — весь лендинг (шапка с макбуком, проблемы, как это
  работает, цифры, призыв к действию)
- `app/layout.tsx` — шрифты (Unbounded + Inter) и метаданные
- `components/CornerMarks.tsx` — уголки-засечки поверх скриншота рекламного
  кабинета
- `components/Ruler.tsx` — разделитель-линейка между пунктами списка
- `public/hero-laptop.jpg` — картинка макбука в шапке

## Что стоит поменять под себя
